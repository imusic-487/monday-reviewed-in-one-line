A [make.fun](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) bounty entry: the funniest one-line review of my own Monday, under 200 characters.

## How it works

`main.py` writes a single line to `/output/entry.txt`:

> One star: Monday's 9am meeting should've been an email, my inbox doubled by lunch, and my coffee went cold before my first sip -- would not Monday again.

153 characters, one line, no title, no explanation — just the review.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
